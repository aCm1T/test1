## Development skyline backdrop

- `development/nightglass-dusk-skyline-v1.png` — original development-only skyline plate generated with OpenAI built-in image generation for this repository on 2026-08-05. It is an optional visual backdrop outside `manifest.json`, the authored asset contract, collision/navigation data, and release capture paths.
- External copyrighted source assets: none supplied.
- Final prompt summary: Fictional dense modern-city skyline at blue-hour dusk viewed from an elevated urban edge; layered mid-rise and high-rise silhouettes, scattered warm window lights, cool storm clouds, natural photographic lighting, wide panorama, no text, logos, trademarks, flags, recognizable landmarks, people, or franchise imagery.
- Modifications: Runtime maps only the sky and skyline portion of the plate onto a distant development-only arc; the original foreground rooftop/floor is UV-cropped and never rendered in the gameplay view.
